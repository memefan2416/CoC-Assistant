# CoC-KP-Assistant
CoC、TRPGの進行の手助けをします

主にココフォリアとの連携、KP・GMのシナリオ進行での負担軽減、PLやKP同士での連携の円滑化での目的で作成しています。
主にデータはローカルとクラウドの二種類あり、ログインしない場合はローカル、ログインした場合はクラウドとなります。
アカウント、パスワードは個人で管理してください。※1
クラウドにSupabaseを使用しており、個人から共有まで使用できます。※2

キャラクターの出力について
出力パターンは2種類あり、ココフォリア用とCoC KP Assistant用です。
ココフォリア用はコピーをしてココフォリアのルームで貼り付けを行えばできます。
CoC　KP Assistant用はココフォリア用より、より多くの情報をコピーでき、別のアカウントへのコピーなどにお使いいただけます
(使用例)
個人アカウントで作成したキャラクターを共用のアカウントへ共有する等

※1　googleやapple等のアカウントは必要ありません。独自のアカウントとなっています。
※2　セキュリティ面があまり複雑化されていないので個人情報の取り扱いにはお気を付けください。
